# YiClinic 益诊所网站

张怿医师（Yi Zhang）的中医针灸诊所官方网站。

## 🌟 诊所信息

- **诊所名称**：YiClinic 益诊所
- **医师**：张怿医师（Yi Zhang）
- **资质**：北京中医药大学硕士，安大略省注册针灸师
- **地址**：Ottawa, Ontario, Canada
- **网站**：www.yiclinic.ca

## 🎯 服务项目

- 针灸治疗 (Acupuncture)
- 面部美容针灸 (Facial Cosmetic Acupuncture)
- 拔罐疗法 (Cupping)
- 刮痧疗法 (Guasha)
- 艾灸疗法 (Moxibustion)

## 🚀 快速开始

### 本地查看
1. 下载所有文件到同一文件夹
2. 双击 `index.html` 在浏览器中打开

### 在线部署
推荐使用以下免费平台：
- **GitHub Pages**：上传到GitHub仓库并启用Pages
- **Netlify**：拖拽文件夹即可部署
- **Vercel**：导入项目一键部署
